# Agent Market — Frontend Step 1

핸드폰·태블릿 중고 마켓의 판매 초안 검토, 사람 게시 승인, 구매 조건 확인, 검색 승인, 결과·상세 화면입니다.

## 실행

추가 패키지 설치 없이 아래 명령으로 실행합니다.

```bash
cd frontend
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. 테스트는 `npm test`로 실행합니다.

## 화면 플로우

- 판매: 판매 정보 입력 또는 Agent 초안 예시 → 초안 검토·수정 → 사람 게시 → 내 판매글
- 구매: 구매 조건 입력 또는 Agent 초안 예시 → 조건 확인 → 사람 검색 승인 → 결과 목록 → 상세
- 결과: 조건 충족과 확인 필요를 구분하고, 확인되지 않은 정보는 정상으로 추정하지 않습니다.
- 데모 모드에서는 12개 매물과 작성한 초안·게시글을 브라우저 `localStorage`에 보관합니다. 브라우저별로 데이터가 따로 저장됩니다.

## 백엔드 연결

`config.js`의 `window.AGENT_MARKET_API_BASE`는 기본적으로 `http://127.0.0.1:8080`입니다. 저장소 루트에서 `npm run start:api`로 백엔드를 실행하면 [API 어댑터](./src/api.js)가 실제 서버를 사용합니다. 값을 빈 문자열로 바꾸면 기존 localStorage 데모 모드를 사용할 수 있습니다. API 계약은 [백엔드 문서](../backend/docs/backend-api.md), 프론트 연동 설명은 [프론트엔드 API 문서](./docs/frontend-api.md)를 참고하세요.

## 범위

Step 1의 핸드폰·태블릿, 판매 승인, 비공개 구매 조건, Rule-based 검색 결과와 Step 2의 공개 수요·역방향 탐색·연결 요청·알림 화면을 제공합니다. **Agent 연결** 화면에서는 권한별 토큰을 발급·폐기할 수 있습니다. Step 2와 Agent 연결은 실제 백엔드 연결이 필요합니다. 로컬 demo 인증 모드에서 상단 구매자/판매자 계정을 바꾸면 한 브라우저에서 양쪽 흐름을 시연할 수 있습니다. 외부 Agent 채팅, 사진 AI 분석, 결제 기능은 포함하지 않습니다.
