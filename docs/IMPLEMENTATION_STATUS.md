## 남은 작업

- 공개 회원가입과 세션·Agent 토큰 발급은 임시 계정으로 확인했고 점검 데이터는 정리했다. 이메일 인증과 비밀번호 복구는 없으므로 계정 복구 정책이 필요하다. 로그인 후 구매 조건→당근 링크는 로컬 브라우저에서만 확인했다.
- 당근 검색은 사용자 주도의 웹 이동이다. 공식 매물 검색 API 사용이나 매물 수집은 확인하지 않았다. 외부 매물의 상태·가격·지역·거래 가능 여부는 당근에서 확인해야 한다.
- 운영 `/mcp`는 독립 MCP SDK 클라이언트와 실제 Claude 대화에서 조회 호출까지 확인했다. Claude에는 `read`만 있는 7일 토큰을 연결했고, 초안 작성·검색 실행·게시·공개는 이 토큰에서 사용할 수 없다. Claude 또는 Cursor에서 초안 작성까지의 실사용 검증은 별도다.
- 저장소는 SQLite 프로토타입이다. 일관된 백업 파일 생성과 무결성 검사는 구현했지만 자동 보존·외부 저장·복구 연습은 운영 환경에서 설정해야 한다. 운영 DB로 PostgreSQL을 쓰려면 어댑터와 마이그레이션을 따로 구현해야 한다.
- 알림은 API 조회 방식이다. 푸시·이메일·백그라운드 작업자는 없다. 만료 상태는 관련 API 접근 시 갱신된다.
- 연결 수락 후 연락 방법·거래 진행, 결제·배송은 문서의 제외 범위다.
- 인증 후 당근 링크를 공개 사이트에서 열어보는 검증은 아직 없다. 루트 Dockerfile은 한 서비스에 세 서버를 묶고, 별도 Docker Compose는 자체 서버용 세 서비스 구성이다.

## 검증

2026-11-13 `npm test`는 백엔드 61개, 프런트엔드 7개를 통과했다. 토큰 폐기 직후 MCP 접근 차단도 포함한다. 로컬 브라우저에서 신규 가입→앱 이동→“100만 원 이하 아이패드 에어 128GB 이상” 조건 정리→당근 검색 링크 표시를 확인했다. 2026-11-07에는 자체 후보 2개 → 공개 구해요 → 판매자 역방향 탐색 → 연결 요청 → 구매자 수락도 확인했다. 11/13 운영 점검은 공개 Web 가입·세션·읽기 전용 토큰 발급·MCP 도구 호출·폐기 즉시 401·임시 계정 삭제까지 통과했다. 실제 Claude 대화에서는 `whoami`와 `browse_listings`를 호출해 `read` 단일 권한과 ACTIVE 공개 매물 12개(전부 샘플)를 확인했다. 운영 Web의 전체 구매·판매 쓰기 시나리오는 별개다. 재현 절차는 [Step 2 시연 가이드](../backend/docs/step2-api.md)에 있다.
