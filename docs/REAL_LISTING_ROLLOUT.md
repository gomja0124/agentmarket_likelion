# 실제 판매 매물 확보·운영

2026-11-13 기준. 기본 시드 매물 12개와 발표용 계정이 등록하는 매물은 모두 시연용이다. 팀이 실제 판매자에게서 받은 물건 정보나 사용 허락을 이 저장소에서 확인하지 못했으므로, 발표용 예시를 실제 거래 가능 물건으로 설명하지 않는다.

## 등록 경로

1. 배포 후 `https://gomja-market.store/sell` 주소를 판매 의사가 있는 사람에게 전달한다.
2. 판매자가 본인 계정으로 가입·로그인하면 바로 판매글 입력 화면으로 이동한다.
3. 본인이 소유하고 판매할 스마트폰·태블릿의 모델, 용량, 가격, 상태, 구성품, 흠집·고장 내용, 실물 사진을 입력한다. 사진은 브라우저에서 크기를 줄인 뒤 저장된다.
4. 판매자가 내용을 검토하고 직접 게시한다. Agent는 초안을 도울 수 있지만 게시할 수 없다.
5. 가격·상태가 바뀌면 수정 초안을 게시한다. 판매를 잠시 중단하면 비활성화하고, 거래가 끝나면 `판매 완료`로 처리한다. 판매 완료된 글은 다시 활성화할 수 없다.

다른 서비스의 판매글·사진은 허락 없이 가져오지 않는다. 현재 당근 연결은 구매자를 당근 공개 검색으로 보내는 링크이며, 당근 매물을 우리 DB에 적재하는 기능이 아니다.

## 매물 노출 규칙

- 운영의 매물 목록, 구매 조건 매칭, 외부 MCP `browse_listings`·`search_listings`는 기본적으로 모든 시연용 매물을 제외한다.
- 발표나 테스트에서는 화면의 `시연용 매물도 보기`, `?samples=1` 링크 또는 MCP의 `includeSamples: true`를 선택해 예시를 볼 수 있다. 예시는 항상 `isSample: true`로 표시된다.
- 발표용 판매자 계정에 등록한 매물은 공개 구해요와의 역매칭·알림·연결 요청 흐름에 참여한다. 기본 시드 12개는 구해요 알림을 만들지 않는다.
- 로컬 `demo` 인증 모드는 기존 시드 기반 테스트 흐름을 유지한다.
- 판매 완료·비활성 매물은 공개 목록과 신규 검색 결과에서 제외된다. 과거 검색 결과 기록은 별도로 남는다.

## 첫 실매물 확보 체크리스트

- 팀원·지인 등 실제 판매 의사가 있는 소수의 판매자부터 시작한다. 판매자 본인이 직접 등록하거나 명시적으로 등록을 허락한 정보만 사용한다.
- 등록 직후 구매자 계정에서 매물 노출·사진·가격·검색 조건 매칭을 확인한다. 외부 Agent에서도 샘플 제외 기본 조회에 나타나는지 확인한다.
- 판매자가 거래 가능 여부를 바꾸면 그날 비활성화 또는 판매 완료 처리한다.
- 운영 지표는 시연용을 뺀 `ACTIVE 매물 수`, 사진·상태·설명 입력 비율, 매칭 후 연결 요청 수로 본다. 현재 실매물 수는 0개로 알려져 있으며, 배포 후 DB 상태는 다시 조회해야 한다.

## 배포 후 확인

새 버전을 배포한 다음 공개 `/sell` 주소가 열리는지, 가입 후 `/#sell`로 가는지, 판매자 계정에서 사진 등록→게시→구매자 검색→판매 완료까지 수행한다. 기존 SQLite 데이터베이스에는 `sold_at` 열이 자동 추가된다. 운영 DB는 배포 전 백업한다.
